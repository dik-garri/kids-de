# 🇩🇪 Wie heißt das? — немецкие слова для детей

Ребёнок нажимает большую кнопку, спрашивает голосом «Как будет по-немецки лампа?» —
и приложение показывает и **произносит** ответ немецким голосом: **die Lampe** 💡.

Один файл `index.html`, без сервера, без обязательных API-ключей.

## Как это работает

| Функция | Технология | Стоимость |
|---|---|---|
| Распознавание речи (русский) | Web Speech API — встроено в браузер | бесплатно, без ключей |
| Перевод | Встроенный словарь ~300 детских слов | бесплатно, офлайн |
| Перевод любых слов и фраз (опция) | Gemini API: цепочка из 6 бесплатных моделей (`3.5-flash-lite` → `3.1-flash-lite` → `2.5-flash-lite` → `3.5-flash` → `3.6-flash` → `2.5-flash`), у каждой свой лимит | бесплатный тариф Google |
| Кэш выученных слов | localStorage — повторные слова не тратят API | бесплатно |
| Немецкое произношение | SpeechSynthesis — встроено в браузер | бесплатно |

Артикли подсвечены цветом (классический приём для запоминания рода):
**der** — синий, **die** — красный, **das** — зелёный.

## Режим «Учить слова» 📚

Кнопка «📚 учить» в шапке переключает приложение в режим сетки слов:

- на экране одновременно 12–24 плитки (зависит от размера экрана),
  остальные слова ждут в запасе; порядок фиксированный, по темам;
- тап по плитке — слово произносится по-немецки, вверху показывается
  перевод с цветным артиклем и кнопка «🎙 Скажи!» — ребёнок повторяет
  слово вслух, приложение распознаёт немецкую речь и хвалит;
- слово выучивается в два этапа (счётчики скрыты): 7 прослушиваний,
  затем 8 правильных ответов викторины «Wo ist …?» — приложение
  спрашивает по-немецки, ребёнок находит картинку;
- честный счёт: быстрые повторные тыки не считаются, максимум
  3 зачёта на слово в день — настоящее интервальное повторение;
- выученная плитка 🎉 исчезает, её место занимает следующее слово;
  раз в неделю старые выученные слова тихо возвращаются на повторение;
- прогресс хранится в localStorage; сброс — в настройках ⚙️;
  панель ⭐ позволяет вручную вернуть выученное слово в игру;
- источник слов задаётся функцией `learnPool()` — в будущем туда можно
  добавить другие наборы слов.

## Публикация на GitHub Pages

```bash
cd kids-de
git init && git add . && git commit -m "Kids German words app"
gh repo create kids-de --public --source=. --push
gh api repos/{owner}/kids-de/pages -X POST -f "source[branch]=main" -f "source[path]=/"
```

Через минуту приложение будет доступно по адресу
`https://<ваш-логин>.github.io/kids-de/`.

> **Важно:** микрофон в браузере работает только по HTTPS — GitHub Pages подходит идеально.

## Включение AI-режима (опционально)

1. Получите бесплатный ключ на [Google AI Studio](https://aistudio.google.com/apikey) (кредитная карта не нужна).
2. В приложении нажмите ⚙️ в правом верхнем углу и вставьте ключ.
3. Ключ хранится только в localStorage этого устройства.

Без ключа приложение полностью работает на встроенном словаре.

## Поддерживаемые устройства

- ✅ Android — Chrome
- ✅ iPad / iPhone — Safari (iOS 14.5+)
- ✅ Компьютер — Chrome, Edge, Safari
- ❌ Firefox — распознавание речи не поддерживается (работает ввод с клавиатуры)

Совет: добавьте страницу на домашний экран планшета («Add to Home Screen») —
она откроется во весь экран, как настоящее приложение.

## Добавить свои слова

Откройте `index.html`, найдите объект `DICT` и добавьте строку:

```js
"пылесос": ["der", "Staubsauger", "🧹"],
```

Формат: `"русское слово": ["артикль (или пустая строка)", "немецкое слово", "эмодзи"]`.
